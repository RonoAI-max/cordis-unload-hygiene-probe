# Cordis Unload Hygiene Probe

[English](README.md) · [開発ロードマップ（英語）](ROADMAP.md)

DeepSeek Harness（DSH）のプラグイン開発者向けライフサイクル診断ツールの技術実証版です。プラグインの解放後に残る一部のリソースを検出し、発生箇所を示します。

## 現在できること

- ローカルにインストールされた実DSHで、専用のテストプラグインを読み込み、Cordisの実ローダーエントリーを解放
- グローバルなinterval、timeout、専用EventEmitterのリスナーを計測し、解放前後を比較
- 生成元のファイル・行・列の特定、人間向けCLI出力とJSON出力
- 正常ケースと意図的リークケースの自動比較、計測復元・テスト後の回収確認
- 新規Windows VMで再現性を確認

正常ケース6/6成功、残留0件。意図的リークケース6/6成功、解放直後に各3件、合計18件を検出しました。テスト終了時には残留リソースを回収し、計測機構の復元を確認しています。同一物理PC上の新規OS・新規ユーザー環境での検証であり、一般のプラグインや別の物理PCに対する精度・互換性は未検証です。

## 実行方法

Windows x64、Node.js v24.18.0（検証時）、対応するローカルDSH Desktopが必要です。DSHの初回起動でランタイム・パッケージの準備を済ませてください。DSH本体は同梱していません。準備後の診断自体にAPIキー・有料モデル呼び出し・npm installは不要でした。

```powershell
node scripts/diagnose.cjs --demo both
node scripts/diagnose.cjs --demo both --json
```

終了コード2は意図的なリーク検出時の正常な結果です。詳細は[英文README](README.md)と[検証結果](docs/validation.md)を参照してください。

## 今後の目標

固定fixtureによる技術実証から、開発者自身の信頼済みプラグインへの適用、対応リソース・誤検出対策の強化、回帰テスト・CI連携、DSHの対応APIを使った統合へ発展させたいと考えています。将来的なUI・配布方法は技術的な検証と開発者の意見を踏まえて決定します。

希望する支援は、AIを活用した継続的な実装・テスト・互換性調査のためのトークン支援、公式ライフサイクルや安全な計測方法に関する技術交流、開発者からのフィードバックです。

## 制約

現段階では信頼済みの固定テスト専用で、汎用プラグイン診断・本番プロファイル・GUI統合・一般的なメモリリーク検出には対応していません。OSレベルの隔離やネットワーク遮断を保証するものではありません。未信頼プラグインには使用しないでください。独立した実証プロジェクトであり、DSH公式の承認を意味しません。ライセンスは作者確認待ちです。
